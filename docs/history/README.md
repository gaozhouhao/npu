# 历史资料

此目录保存原实验记录、源码审计、目录迁移映射及旧测量结果。其中的文件名、命令、日期目录和源码快照描述当时的状态；当前项目以[架构说明](../architecture.md)、[接口索引](../module_interfaces.md)、[验证记录](../validation.md)和根Makefile为准。

- `learning/`：VCS、综合、时序、DFT、ATPG、MBIST的学习背景与实验日志。
- `compiler_delivery.md`：原SmallCNN编译工具交付记录。
- `rtl_contract.json`：历史源码SHA256快照，仅归档，不参与当前编译。
- `code_audit.md`、`reference/`、`validation/`：历史审计、旧目录信息和性能测量。
